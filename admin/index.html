カレンダーの予定を更新

予定はGitHubの events.json で管理します。リポジトリの編集権限があるGitHubアカウントで更新してください。

  1. 下のボタンから予定データを開きます。
  2. events の中の予定を追加・編集・削除します。
  3. 「Commit changes」で保存します。GitHub Pagesの公開処理が完了するとカレンダーに反映されます。

予定1件の書き方：

{
  "id": "event-001",
  "date": "2026-12-01",
  "title": "イベント名",
  "time": "14:00",
  "details": "イベントのご案内"
}

日付は YYYY-MM-DD、時間は HH:mm。時間・詳細が不要なら "" にします。予定が複数ある場合は、予定同士をカンマで区切ります。予定をすべて消す場合は {"events": []} にします。

この説明の予定はサンプルです。カレンダーには登録されていません。
